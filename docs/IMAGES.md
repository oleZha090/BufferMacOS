# Скриншоты и картинки

Нажмите **Control + Shift + Cmd + 4**, чтобы скопировать выделенный скриншот в буфер macOS. Он появится в истории с превью и размером в пикселях. Обычный Shift + Cmd + 4 сохраняет файл на диск; для попадания в историю скопируйте картинку или сам файл изображения.

Поддерживаются PNG, TIFF (в том числе скриншоты macOS), JPEG и другие растровые представления, которые распознаёт ImageIO macOS, например GIF и HEIC. Если приложение кладёт несколько представлений одной картинки в буфер, Cliply сохраняет доступные исходные байты в пределах лимита. Картинка имеет приоритет перед сопровождающей текстовой ссылкой. Копирование одного файла изображения в Finder тоже поддерживается: его содержимое сразу читается в память, поэтому дальнейшее перемещение/удаление файла не ломает запись истории. Прочие файлы и групповые копирования файлов в историю не импортируются.

Выберите изображение и нажмите **Enter** либо кликните по нему. Cliply вернёт исходные данные картинки в NSPasteboard и отправит Cmd+V в прежнее приложение. Поле назначения должно поддерживать вставку изображений — например, редактор документа или поле вложений мессенджера. Обычная текстовая строка может не принять картинку. Без Accessibility изображение остаётся в буфере для ручного Cmd+V.

Превью создаётся на фоновой очереди и ограничено 256 пикселями; оригинал для вставки не уменьшается. Максимум на одну картинку — **64 МиБ исходных представлений и 40 мегапикселей**, бюджет всей истории с превью — **128 МиБ**. Повторные картинки определяются по SHA-256 основного исходного представления; перекодированная версия того же изображения может стать отдельной записью. Поиск находит картинки по имени файла, размеру, формату и словам «изображение», «картинка», «скриншот», `image`, `screenshot`; OCR и поиск текста внутри картинки не выполняются.
