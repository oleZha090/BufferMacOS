# Проверка Cliply на Mac

Выполнять на macOS 14+ на Intel и Apple Silicon. Эти проверки требуют реального пользовательского сеанса; CI/XCTest с моками их не заменяют. Пока проект разрабатывается на Windows, пункты ниже остаются непроверенными.

## Сборка и жизненный цикл

- [ ] Открыть `Cliply.xcodeproj`, собрать Debug и Release. Выполнить XCTest.
- [ ] Проверить универсальную сборку `lipo -archs Cliply.app/Contents/MacOS/Cliply`: `arm64 x86_64`.
- [ ] При запуске есть значок clipboard в Menu Bar, Dock-иконки и открытой панели нет.
- [ ] Имя Cliply отображается в Finder, Settings, Menu Bar, обоих языках и Release; внутри DMG лежит `Cliply.app` с чёрно-белой иконкой. Проверить разные размеры значков Finder и Retina.
- [ ] Значок читается в светлой и тёмной теме; настройки не содержат выключателя значка.
- [ ] Левый клик показывает историю; правый — меню со всеми пятью действиями.
- [ ] Закрыть историю и Settings. Приложение остаётся запущенным и собирает новые копирования.
- [ ] Sleep/wake не создаёт второй таймер и не останавливает сбор. Activity Monitor: в покое нет постоянной нагрузки.
- [ ] Quit завершает процесс. Новый запуск начинает с пустой истории, текущее содержимое системного буфера не очищается.

## История и приватность

- [ ] Скопировать 11 различных текстов с помощью ⌘C и контекстного меню. Остались ровно 10, удалён первый.
- [ ] Повторно скопировать старый текст: одна запись с этим текстом на первом месте.
- [ ] Проверить многострочный текст, URL, Unicode, эмодзи и пробелы в начале/конце: после вставки текст совпадает полностью.
- [ ] Пробельные строки, изображения, файлы и текст более 100 KiB UTF-8 игнорируются.
- [ ] Проверить текст с типами `org.nspasteboard.ConcealedType` и `org.nspasteboard.TransientType` через тестовую утилиту: его нет в истории.
- [ ] Удаление одной записи и полная очистка не изменяют системный буфер: проверить ручным ⌘V.
- [ ] Выбор старой записи для вставки не добавляет и не переставляет её в истории. Следующее внешнее копирование отслеживается.
- [ ] Поиск без учёта регистра фильтрует историю. Все 10 записей доступны прокруткой и стрелками.
- [ ] Дисковые настройки содержат только сочетание клавиш, язык и тему; в Console нет содержимого записей; сетевых обращений от Cliply нет.

## Панель и клавиатура

- [ ] Из Safari, TextEdit, VS Code и мессенджера нажать ⌘⇧V. Панель появляется возле мыши, курсор не перемещается.
- [ ] Проверить все четыре края и углы каждого монитора; панель не пересекает Dock/Menu Bar.
- [ ] Проверить монитор слева от основного (отрицательные X), ниже (отрицательные Y), сверху и справа. Проверить Retina и обычный монитор вместе.
- [ ] Проверить полноэкранное приложение и переключение Spaces: панель на активном рабочем пространстве.
- [ ] Сразу печатать запрос после открытия, без клика по поиску. ⌘A, ⌘C, ⌘V, ⌘X работают в поиске.
- [ ] ↑/↓ изменяют выделение и прокручивают к нему; Return и цифровой Enter выбирают запись; клик делает то же.
- [ ] Проверить ввод с IME: Return завершает композицию, не вставляет запись преждевременно.
- [ ] Escape, повторная горячая клавиша и клик за панелью закрывают историю без изменения буфера.
- [ ] После клика по строке и сразу после повторного Return вставка выполняется лишь один раз.

## Язык и оформление

- [ ] В Settings → General → Interface переключить English → Русский → English без перезапуска. Проверить все три вкладки, заголовки окон, поиск, пустую историю, кнопки, tooltips и меню значка.
- [ ] Проверить обе локализации подсказки ручной вставки без Accessibility, ошибки конфликта hotkey и статуса автозапуска. Системные диалоги macOS сохраняют собственный язык системы.
- [ ] Сохранённый текст, включая многострочный Unicode и `%`, не переводится и не меняется при переключении. Поисковый запрос и выбранная запись сохраняются.
- [ ] В режиме системного языка на русской macOS выбран русский, на английской — английский, при отсутствии обоих в предпочтениях — английский.
- [ ] Выбрать светлое оформление при тёмной macOS и тёмное при светлой. Проверить контраст текста/поиска/выделения, фон панели, все вкладки, нативный заголовок Settings и подсказку вставки.
- [ ] Выбрать системное оформление, изменить тему macOS при открытых Settings: Cliply следует изменению без перезапуска.
- [ ] Значок Menu Bar остаётся читаемым на системной панели независимо от выбранной темы Cliply.
- [ ] Перезапустить приложение: выбранные язык и тема сохранены, история пуста. Проверить одинаковое поведение на установленном DMG из Releases.

## Настройки сочетания

- [ ] Записать сочетания с Cmd, Option, Control, Shift; сохранить после перезапуска. Проверить Reset to Default.
- [ ] Прежняя комбинация прекращает работать после смены; новая открывает и закрывает панель.
- [ ] Только модификаторы, обычная клавиша без Command/Option/Control и повреждённые настройки не ломают приложение.
- [ ] При конфликте с занятым системным/другим приложением сочетанием показана ошибка, прежняя комбинация сохранена.
- [ ] Отмена записи через Escape и уход фокуса возвращают прежний hotkey. Текущее сочетание можно снова записать.
- [ ] Если hotkey не удалось зарегистрировать при старте, Menu Bar остаётся доступным, ошибка видна в Keyboard.

## Вставка и разрешения

- [ ] Отозвать Accessibility. История, поиск, Menu Bar и hotkey продолжают работать без системного запроса.
- [ ] Без разрешения у Enter подпись «Копировать». Кнопка «Включить автовставку» в истории закрывает панель и открывает запрос/системные настройки без изменения буфера и без отправки Cmd+V.
- [ ] Разрешить Cliply, вернуться в исходное текстовое поле и снова открыть историю: предупреждение исчезло, у Enter подпись «Вставить». Выбранная стрелками запись вставляется в это поле по Enter, без ручного Cmd+V.
- [ ] Выбрать запись без разрешения: панель закрылась, текст в NSPasteboard, подсказка объясняет ⌘V, автоматического события нет.
- [ ] В подсказке после ручного копирования кнопка «Включить автовставку» тоже открывает разрешения. Она не запускает отложенную вставку в окно системных настроек.
- [ ] Через Privacy запросить разрешение и разрешить Cliply в System Settings. Вернуться: статус обновлён.
- [ ] В двух разных документах TextEdit, Safari, IDE и мессенджере вставить старую запись. Текст попал в прежнее поле, без добавочных символов и дублей.
- [ ] Открыть панель при указателе мыши на другом мониторе: вставка идёт в прежнее поле, а не в поле под мышью.
- [ ] Быстро выбрать запись, удерживая модификаторы: событие не посылается до их отпускания; при превышении ожидания — ручная вставка.
- [ ] Закрыть исходное приложение, пока открыта история: выбранный текст остаётся в буфере, нет вставки в другое приложение.
- [ ] Перехватить foreground/focus другим окном во время активации: нет вставки в произвольное приложение.
- [ ] Изменить системный буфер до подтверждения активации: новая копия сохраняется, автоматическая вставка отменена с объяснением.
- [ ] Проверить приложение, не предоставляющее AX-фокус, и защищённое поле/Secure Event Input: при отказе доступна ручная вставка.
- [ ] Смена подписи/папки установки: если macOS сбросила разрешение, UI корректно отражает это и работает fallback.
- [ ] При искусственной ошибке записи NSPasteboard исходные данные и запись истории сохраняются; панель показывает ошибку. Не перезаписывается буфер, изменённый другим приложением во время rollback.

CGEvent не возвращает результат вставки в конкретное поле. После отправки единственной пары событий повторных попыток нет; если приложение игнорирует Cmd+V, пользователь может вставить оставленный в буфере текст вручную.

## Автозапуск

- [ ] Установить стабильную подписанную копию в `/Applications`, включить Launch at Login. UI отображает реальный `SMAppService.status`.
- [ ] Для `requiresApproval` показано ожидание и переход в Login Items; после одобрения — Enabled.
- [ ] Выйти из учётной записи и войти: Cliply запускается со значком и пустой историей, без панели и Dock.
- [ ] Выключить автозапуск, повторить вход: приложение не стартует. Ошибка ServiceManagement отображается пользователю.
